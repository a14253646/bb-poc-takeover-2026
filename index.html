Subdomain Takeover - Proof of Concept

This is a security research demonstration. The subdomain ghssm.tooling.travix.com is currently vulnerable to takeover via dangling GitHub Pages CNAME.

Vulnerability Details

  • DNS CNAME: ghssm.tooling.travix.com → xivart.github.io
  • The original GitHub Pages site at xivart.github.io returns 404 (Site not found)
  • No DNS TXT verification record exists, allowing custom domain claim by any GitHub user
  • This page is being served from an unauthorized GitHub repository to demonstrate exploitability

Researcher Notice

This PoC has been reported responsibly to Trip.com via HackerOne.

This GitHub repository will be deleted and the custom domain configuration removed within 24-48 hours, regardless of the disclosure response timeline, to ensure no malicious actor can re-claim the dangling resource via this exact route.

If you are from Trip.com / Travix Engineering: please contact your HackerOne triager to receive the full report.

Recommended Remediation

  1. Remove the CNAME record for ghssm.tooling.travix.com if the subdomain is no longer needed
  2. Or re-create the GitHub Pages site at xivart.github.io
  3. Add DNS TXT verification per GitHub's docs
